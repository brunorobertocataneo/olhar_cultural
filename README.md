# Olhar Cultural — Angola

Site sobre a história e a literatura angolanas, com textos e exemplos organizados por gênero.

**[Abrir demonstração](https://brunorobertocataneo.github.io/olhar_cultural/)**

## O que você encontra

- Contexto histórico e características literárias.
- Autores e obras, com seções de conto, crônica, charge, tirinha e poema.

## Executar localmente

Baixe ou clone o repositório e sirva a pasta raiz com um servidor estático. Com Python 3 instalado, execute `python -m http.server 8000` e acesse [localhost:8000](http://localhost:8000/).
